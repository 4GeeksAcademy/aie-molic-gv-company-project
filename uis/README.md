# User interfaces (`uis/`)

This folder groups user-interface projects in the AI Engineering monorepo. Each application should document its own setup and purpose in its respective folder.

## Projects

- **[TrackFlow website](./website/README.md)** (`website/`): corporate landing page (`index.html`) and multi-step information-request form (`application.html`, `validation.js`). Its README provides setup, commands, tests, and 4Geeks delivery requirements (in Spanish).
- **`backoffice/`**: planned location for future administration interfaces; this does not imply a working application exists.

This file is an index. Tailwind compilation, web server, and Codespaces instructions are maintained in the [website's technical README](./website/README.md), rather than duplicated here.
